# Аида — портфолио инженера по тестированию

# Обо мне

Занимаюсь автоматизацией тестирования веб-приложений и API на Python. Разрабатываю позитивные и негативные проверки, использую Page Object Model, фикстуры и параметризацию Pytest, работаю с Allure.

В портфолио представлены пять проектов для сервисов заказа еды и аренды самокатов.

# Навыки и инструменты

* Язык программирования: Python.
* Автоматизация тестирования: Pytest, Selenium WebDriver, Requests.
* Подходы: Page Object Model, параметризация, фикстуры.
* Тестирование: функциональное, UI, API, позитивные и негативные сценарии, проверки в Google Chrome и Mozilla Firefox.
* Отчётность и работа с кодом: Allure, Git, GitHub.

# №1. Stellar Burgers — регистрация и личный кабинет

Автоматизация проверок веб-приложения для заказа бургеров. Цель — проверить доступ пользователей к аккаунту и навигацию по интерфейсу.

Стек: Python, Selenium WebDriver, Pytest.

Что сделано:

* Написаны тесты успешной регистрации и ошибки при некорректном пароле.
* Проверены четыре способа входа в аккаунт.
* Покрыты переходы в личный кабинет, возврат в конструктор и выход из аккаунта.
* Добавлены проверки переключения разделов «Булки», «Соусы» и «Начинки».
* Тесты сгруппированы по функциональности, фикстуры и локаторы вынесены в отдельные файлы.

Результат: создан набор UI-автотестов для повторной проверки регистрации, авторизации и навигации.

Код проекта (ветка develop)— https://github.com/yrvoxxoo-ops/stellar-burgers-auth-tests_1/tree/develop

# №2. Яндекс Самокат — оформление заказа через интерфейс 

Автоматизация тестирования сервиса аренды самокатов. Цель — проверить путь пользователя от перехода к форме до успешного создания заказа.

Стек: Python, Selenium WebDriver, Pytest, Page Object Model, Allure.

Что сделано:

* Автоматизированы проверки раскрытия ответов в разделе «Вопросы о важном».
* Написаны тесты оформления заказа через верхнюю и нижнюю кнопки «Заказать».
* Проверено появление сообщения об успешном создании заказа.
* Добавлены проверки переходов по логотипам «Самокат» и Яндекса.
* Применены Page Object Model и параметризация для запуска проверок с разными данными.
* Подготовлен Allure-отчёт о результатах тестирования.

Результат: автоматизированы проверки оформления заказа, раздела вопросов и переходов между страницами.

Код проекта (ветка develop)—https://github.com/yrvoxxoo-ops/scooter-ui-tests_2/tree/develop

# №3. Яндекс Самокат — API курьеров и заказов

Тестирование API сервиса аренды самокатов. Цель — проверить создание и авторизацию курьеров, работу с заказами и обработку некорректных данных.

Стек: Python, Requests, Pytest, Allure.

Что сделано:

* Написаны тесты создания курьера: успешная регистрация, запрет дублирования и отсутствие обязательных полей.
* Проверена авторизация с корректными, неверными и неполными учётными данными.
* Добавлены проверки создания заказа с цветами BLACK, GREY, обоими цветами и без указания цвета.
* Проверено наличие поля track в ответе при создании заказа.
* Автоматизирована проверка получения списка заказов.
* Методы работы с API, конфигурация и тестовые данные вынесены в отдельные модули.
* Сохранены результаты выполнения тестов для Allure.

Результат: создан набор API-автотестов для четырёх групп операций с позитивными и негативными проверками.

Код проекта (ветка develop) - https://github.com/yrvoxxoo-ops/scooter-api-tests_3/tree/develop

# №4. Stellar Burgers — конструктор и лента заказов

Автоматизация UI-тестирования сервиса заказа бургеров. Цель — проверить работу конструктора, отображение заказов и обновление счётчиков в двух браузерах.

Стек: Python, Selenium WebDriver, Pytest, Page Object Model, Allure, Google Chrome, Mozilla Firefox.

Что сделано:

* Проверены переходы в разделы «Конструктор» и «Лента заказов».
* Добавлены тесты открытия и закрытия окна с деталями ингредиента.
* Проверено увеличение счётчика ингредиента при добавлении в заказ.
* Написаны проверки обновления счётчиков «Выполнено за всё время» и «Выполнено за сегодня» после создания заказа.
* Проверено появление номера созданного заказа в разделе «В работе».
* Применён Page Object Model, подготовлены фикстуры для запуска браузеров и подготовки пользователей.
* Настроен запуск тестов в Chrome и Firefox с сохранением результатов для Allure.

Результат: создан набор UI-автотестов для проверки конструктора и ленты заказов в двух браузерах.

Код проекта (ветка develop3) — https://github.com/yrvoxxoo-ops/stellar-burgers-ui-tests_4/tree/develop3
